# propose-improvement

## When to use
A specialized repo discovers a missing skill, a clearer invariant, or a better verification pattern.

## Steps
1. Write a short proposal (problem, proposed change, evidence) in the specialized repo’s progress.md or a docs/ note.
2. If the change is small and clearly beneficial, open a PR or push a branch against Beckettsapere824/agent-harness.
3. Reference the proposal from the specialized repo’s MEMORY.md so future agents see it.
4. Do not silently diverge the local harness copy without a corresponding base-repo update path.
